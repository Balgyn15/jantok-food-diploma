# Key-scenario prototype — text wireframe

Owner: Ayana. YouTrack: JANTOK-8. Status: first interaction draft; visual mockups and user feedback are pending.

1. **Welcome / sign in:** language choice, phone entry, one-time-code flow, clear error/retry state.
2. **Household setup:** add each eating member, name and age category; show completion count.
3. **Nutrition questionnaire:** restrictions and preferences are entered per member; the current member is always visible.
4. **Recommendation:** each member's suggested meals and any unavailable alternatives are explained.
5. **Quote:** 30-day period, included meals, price breakdown and change rules shown before confirmation.
6. **Subscription calendar:** selected day, meal changes and delivery status; clear cut-off message when editing is closed.

The intended user path is 1 → 2 → 3 for every member → 4 → 5 → 6. Use synthetic examples only. This text wireframe does not substitute for the planned visual mockups or a validated usability test.
