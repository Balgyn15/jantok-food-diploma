# Staff frontend component — planned

Technology: Next.js/React/TypeScript. Planned areas: authenticated staff access, meal/menu maintenance, order status updates and daily kitchen plan. This is the staff web interface; the customer interface is in the mobile component.

The staff client uses the same backend authority as mobile. It will not duplicate price, eligibility or authorization logic. The first-pre-defense interaction example is in [UX_PROTOTYPE.md](../../docs/UX_PROTOTYPE.md); a separate demo dashboard implementation is not part of this snapshot.
